# python

Repositório com os desafios técnicos do **MBA em Engenharia de Software com IA (Full Cycle)**. Cada desafio fica em sua própria pasta na raiz, com contexto, arquitetura e instruções de execução no README correspondente.

### [mba-ia-desafio-ingestao-busca](mba-ia-desafio-ingestao-busca/README.md)

**Ingestão e busca semântica com LangChain + pgVector.** Um PDF é ingerido em um banco vetorial (PostgreSQL + pgVector) e um chat de linha de comando responde perguntas com base apenas no conteúdo do documento.
**README:** [mba-ia-desafio-ingestao-busca/README.md](mba-ia-desafio-ingestao-busca/README.md)

### [mba-ia-pull-evaluation-prompt](mba-ia-pull-evaluation-prompt/README.md)

**Pull, otimização e avaliação de prompts com LangChain + LangSmith.** O prompt semente é refatorado com técnicas avançadas de Prompt Engineering, publicado de volta ao Hub (público) e avaliado automaticamente com 5 métricas — meta: todas ≥ 0.8.
**README:** [mba-ia-pull-evaluation-prompt/README.md](mba-ia-pull-evaluation-prompt/README.md)

### [mba-ia-desafio-design-docs-com-ia](mba-ia-desafio-design-docs-com-ia/README.md)

**Design docs gerados com IA.** A transcrição de uma reunião técnica + o código de um OMS (Node.js/TypeScript, Prisma/MySQL) são transformados em um pacote de documentação — PRD, RFC, FDD, 7 ADRs e tracker de rastreabilidade — para a feature de webhooks de notificação de pedidos.
**README:** [mba-ia-desafio-design-docs-com-ia/README.md](mba-ia-desafio-design-docs-com-ia/README.md)
